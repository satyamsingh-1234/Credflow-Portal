# CredFlow Master Analytics & Telecalling CRM

Automated Customer Usage Health Evaluation • Interakt WhatsApp API • Single-Click Outreach Workflow

## How to Run Locally

```bash
pip install -r requirements.txt
streamlit run credflow_portal.py
```

## How to Deploy on Streamlit Cloud

1. Create a public/private repository on GitHub.
2. Upload/Push all files from this `credflow_deploy` directory to your GitHub repository.
3. Sign in to [share.streamlit.io](https://share.streamlit.io) using your GitHub account.
4. Click **New App**, select your repo, and set Main file path to `credflow_portal.py`.
5. Click **Deploy!**
